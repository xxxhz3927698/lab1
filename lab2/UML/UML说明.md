# UML 图说明

本目录使用 PlantUML 绘制，源文件为 `.puml`，导出图片为 `.png`。

## 图清单

| 文件 | 类型 | 作用 |
|---|---|---|
| `UML类图.png` | 结构性图 | 核心类图总览：领域模型、服务、仓储、接口层的关系 |
| `UML类图-领域模型.png` | 结构性图 | 买方、卖方、管理员、商品、预约、审核记录、日志等核心领域对象 |
| `UML类图-服务与仓储.png` | 结构性图 | 应用服务、仓储接口和 Web 控制器之间的依赖 |
| `UML组件图.png` | 结构性图 | 客户端、接入层、业务模块、数据库和对象存储之间的组件关系 |
| `UML用例图.png` | 行为性图 | 游客、买家、卖家、管理员四类角色的用例和权限边界 |
| `UML状态图-商品.png` | 行为性图 | 商品从草稿到售出/违规移除的状态转换 |
| `UML状态图-预约.png` | 行为性图 | 预约从待确认到完成/取消/拒绝/过期的状态转换 |
| `UML活动图-交易主流程.png` | 行为性图 | 搜索、预约、确认、线下完成的主业务流程 |
| `UML时序图-卖家确认预约.png` | 交互性图 | 多人待确认、卖家确认、事务锁、自动拒绝和旧页面 409 |

## 设计说明

- 采用模块化单体 + 分层架构：Web 接口层、应用服务层、领域模型层、仓储接口层、数据层。
- 商品和预约分别使用状态机控制；未列出的状态转换一律按禁止处理。
- 预约确认使用商品行锁、事务和唯一索引，保证同一商品最多一条已确认预约。
- 旧页面操作使用版本号校验，冲突返回 409。
- 违规移除会联动取消相关预约，并保留操作日志。

## 渲染命令

在 Ubuntu 中安装 PlantUML、Graphviz 和中文字体后执行：

```bash
cd lab2/UML
plantuml -tpng -charset UTF-8 *.puml
```

本套图使用 PlantUML 1.2020.02 渲染，中文字体为 `Noto Sans CJK SC`。
