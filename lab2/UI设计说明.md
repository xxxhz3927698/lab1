# 二手交易平台 UI 设计说明

## 1. 设计定位

本套界面为实验二的高保真 UI 设计稿，参考闲鱼的移动端信息架构和视觉语言：

- 黄色主色、黑色文字、白色卡片
- 顶部搜索 + 分类标签
- 双列商品瀑布流
- 商品详情底部的预约操作栏
- 角色化底部导航
- 状态标签、空状态、确认弹层

不复制闲鱼的商标、Logo、吉祥物或图片素材，只参考其移动端交易产品的布局和交互方式。

设计尺寸：390 × 844（2 倍导出为 780 × 1688 PNG）。

## 3. 关键 UI 状态

- 商品状态：草稿、待审核、在售、已预订、已售出、已下架、审核未通过、违规移除
- 预约状态：待确认、已确认、已完成、已取消、已拒绝、已过期
- 危险操作：下架、违规移除、禁用用户都使用二次确认或弹层
- 空状态：无商品、无预约、无日志都有独立空状态
- 权限：不同角色只显示自己的底部导航和操作按钮
