# 二手交易平台原型

这是课程项目的可运行原型，当前完成第 1 阶段：账号、角色权限和数据库基础。

## 技术栈

- Node.js 24
- Express 4
- Node 内置 `node:sqlite`（SQLite）
- 原生 HTML/CSS/JS

## 运行

```bash
cd app
npm install
npm start
```

打开：

- 登录页：http://localhost:3000/login.html
- 工作台：http://localhost:3000/

也可以修改端口：

```bash
PORT=3100 npm start
```

## 默认管理员

首次启动会自动创建管理员账号：

- 账号：`admin`
- 密码：`Admin@12345`

也可以通过环境变量覆盖：

```bash
ADMIN_ACCOUNT=admin ADMIN_PASSWORD='你的密码' npm start
```

首次登录后建议使用“修改密码”接口或重新初始化数据库。原型阶段管理员账号不开放公开注册。

## 已实现

- 用户表、会话表、分类表
- 商品、预约、审核记录、操作日志基础表
- 买家/卖家自助注册
- 账号密码登录、退出、当前会话查询
- 密码 scrypt 加盐哈希
- HttpOnly Cookie 会话，2 小时过期
- 连续 5 次登录失败锁定 15 分钟
- 买家/卖家/管理员角色中间件
- 关键操作日志：注册、登录、登录失败、退出、修改密码
- 基础工作台页面和登录/注册页
