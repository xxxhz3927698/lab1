# 二手交易平台原型

这是课程项目的可运行原型，当前完成第 4 阶段：账号权限、商品管理、审核、预约交易、违规处理、用户管理、日志与统计。

## 技术栈

- Node.js 24
- Express 4
- Node 内置 `node:sqlite`（SQLite）
- 原生 HTML/CSS/JS

## 运行

```bash
cd app
npm install
npm start
```

打开：

- 登录页：http://localhost:3000/login.html
- 工作台：http://localhost:3000/

也可以修改端口：

```bash
PORT=3100 npm start
```

## 默认管理员

首次启动会自动创建管理员账号：

- 账号：`admin`
- 密码：`Admin@12345`

也可以通过环境变量覆盖：

```bash
ADMIN_ACCOUNT=admin ADMIN_PASSWORD='你的密码' npm start
```

### 演示数据（可选）

```bash
npm run seed:demo
```

会创建演示卖家 `seller_demo / Demo12345`、买家 `buyer_demo / Demo12345` 和 6 件不同状态的商品。

### HTTPS 部署

本地 HTTP 调试时不要设置 `COOKIE_SECURE=true`。只有部署到 HTTPS 时才设置：

```bash
COOKIE_SECURE=true npm start
```

首次登录后建议使用“修改密码”接口或重新初始化数据库。原型阶段管理员账号不开放公开注册。

## 已实现

- 用户表、会话表、分类表
- 商品、预约、审核记录、操作日志基础表
- 买家/卖家自助注册
- 账号密码登录、退出、当前会话查询
- 密码 scrypt 加盐哈希
- HttpOnly Cookie 会话，2 小时过期
- 连续 5 次登录失败锁定 15 分钟
- 买家/卖家/管理员角色中间件
- 关键操作日志：注册、登录、登录失败、退出、修改密码
- 商品草稿、编辑、提交审核
- 管理员审核通过/驳回，驳回必须填写理由
- 商品查询：关键词、分类、价格区间、状态、排序、分页
- 商品详情、卖家商品管理、管理员审核页面
- 商品版本号与旧页面 409 冲突处理
- 已发布商品修改后重新审核；已发布商品可以下架
- 商品操作日志：创建、修改、提交审核、通过、驳回、下架
- 买家发起预约、待确认 24 小时过期
- 同一商品多条待确认预约，卖家确认一条后其他自动拒绝
- 确认时事务锁定商品，价格快照，商品变为已预订
- 买家取消待确认预约；买卖双方取消已确认预约
- 卖家完成交易，商品变为已售出，预约变为已完成
- 已确认 7 天未完成自动过期并释放商品
- 预约幂等请求编号、并发确认和旧页面版本冲突
- 预约操作日志
- 管理员违规移除：取消相关待确认/已确认预约，已售出商品不受影响
- 管理员禁用/启用用户，禁用后会话立即失效
- 管理员按操作者、类型、目标、时间查询操作日志
- 卖家统计和平台统计（日期范围、商品状态、分类、每日新增、每日完成）

## 页面

- `/login.html`：登录/注册
- `/`：工作台
- `/market.html`：商品市场
- `/product.html?id=1`：商品详情
- `/seller/products.html`：卖家商品管理
- `/seller/product-edit.html`：新建/编辑商品
- `/reservations.html`：买家我的预约
- `/seller/reservations.html`：卖家预约处理
- `/admin/review.html`：管理员审核
- `/admin/violations.html`：管理员违规处理
- `/admin/users.html`：管理员用户管理
- `/admin/logs.html`：管理员操作日志
- `/stats.html`：卖家/平台统计

## 测试

```bash
npm test
```

当前测试覆盖：健康检查、注册、重复账号、管理员禁止公开注册、登录、退出、连续失败锁定；商品“草稿→提交审核→通过→重新审核→驳回→修改→重新提交→下架”的完整生命周期；预约创建、幂等重放、重复预约、多人待确认、并发确认、自动拒绝其他预约、完成、取消、卖家拒绝、待确认/已确认过期释放商品；违规移除、用户禁用/启用、日志查询和统计。
